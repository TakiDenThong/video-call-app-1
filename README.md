# Video Call App

A simple video call application using **WebRTC** and **Socket.io**.

## Features:
- Real-time video calling
- Admin and member roles
- WebRTC for peer-to-peer communication
- Signaling server using **Socket.io**

## Requirements:
- Node.js 14.x or later
- npm
